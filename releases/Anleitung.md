# E-Mail für Claude – Anleitung

Mit dieser Erweiterung kann Claude Ihre E-Mails lesen, durchsuchen und Antwortentwürfe schreiben. Claude verschickt nie selbst etwas: Entwürfe landen im Ordner „Entwürfe“, und Sie entscheiden, ob Sie sie senden.

## Was Sie brauchen

- Die App **Claude Desktop**, installiert und angemeldet.
- Die Datei **mailbox-….mcpb**, die neben dieser Anleitung liegt.
- Ihren Computer im **Büronetz**. Von zu Hause oder unterwegs kann Claude Ihre E-Mails nicht abrufen.

## 1. Erweiterung installieren

1. Doppelklicken Sie auf die Datei **mailbox-….mcpb**. Claude Desktop öffnet sich.
2. Klicken Sie auf **Installieren**.
3. Die Felder „Mailserver“ und „Port“ lassen Sie, wie sie sind.

Falls sich beim Doppelklick nichts tut: Öffnen Sie in Claude Desktop die Einstellungen, dann „Erweiterungen“, und ziehen Sie die Datei in das Fenster.

## 2. Postfächer einrichten

1. Schreiben Sie in einem neuen Chat: **Postfächer verwalten**
2. Es erscheint eine Ansicht „Ihre E-Mail-Postfächer“.
3. Tragen Sie für jedes Postfach die E-Mail-Adresse, den Benutzernamen und das Passwort ein und klicken Sie auf **Postfach hinzufügen**.

**So finden Sie Benutzername und Passwort:** Öffnen Sie Ihr E-Mail-Programm im Browser. Klicken Sie links mit der rechten Maustaste auf die E-Mail-Adresse und wählen Sie „Konto bearbeiten“. Dort können Sie Benutzername und Passwort kopieren.

Ihre Passwörter werden sicher auf diesem Computer gespeichert. Claude bekommt sie nicht zu sehen. Schreiben Sie Passwörter deshalb nie in den Chat, sondern nur in diese Ansicht.

## 3. Claude nutzen

Schreiben Sie einfach, was Sie möchten, zum Beispiel:

- „Zeig mir die neuen E-Mails.“
- „Suche die E-Mails von Frau Müller aus dieser Woche.“
- „Schreib einen Antwortentwurf auf die letzte E-Mail von Herrn Schmidt.“

Wenn Sie mehrere Postfächer haben, nennen Sie das Postfach, z. B. „im Postfach projekt-a@firma.de“. Ohne Angabe nimmt Claude das Postfach, das in der Ansicht mit „Wird verwendet, wenn Sie kein Postfach nennen“ markiert ist.

Entwürfe prüfen und senden Sie wie gewohnt in Ihrem E-Mail-Programm im Browser, im Ordner „Entwürfe“.

## Passwort geändert oder Postfach nicht mehr nötig

Schreiben Sie **Postfächer verwalten**. Bei jedem Postfach finden Sie:

- **Ändern**: neuen Benutzernamen oder neues Passwort eintragen.
- **Entfernen**: das Postfach löschen. Sie werden vorher noch einmal gefragt.

## Erweiterung entfernen

1. Schreiben Sie **Postfächer verwalten** und klicken Sie unten auf **Alle Zugangsdaten löschen**. Sonst bleiben die Passwörter auf dem Computer gespeichert.
2. Entfernen Sie danach die Erweiterung in Claude Desktop unter Einstellungen → Erweiterungen.

## Wenn etwas nicht klappt

Wenden Sie sich an die Person, die Ihnen die Erweiterung gegeben hat. Wenn in der Ansicht eine „Technische Meldung“ steht, schicken Sie diese bitte mit, zum Beispiel als Bildschirmfoto.
